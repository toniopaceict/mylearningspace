Lesson Overview

In this lesson, you will learn how to convert organised text into a table in Microsoft Word.

By the end of this lesson, you should be able to:

  • Identify the separator used in the text.
  • Convert the text into a table.
  • Adjust the table so that the information is displayed clearly.
