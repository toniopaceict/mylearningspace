Text to Table

My Lesson 1

Lesson Overview

In this lesson, you will learn how to convert organised text into a table in Microsoft Word.

By the end of the lesson, you should be able to identify the separator used in the text, convert the text into a table and adjust the table so that the information is displayed clearly.
