To create a table from text in Microsoft Word, first Blank the text. Then go to the Blank tab, choose Blank and select Blank. Finally, check the Blank before clicking OK.

Remember the sequence used in Word: select the text, use the Insert tab, choose Table, select Convert Text to Table and check the separator before confirming.
