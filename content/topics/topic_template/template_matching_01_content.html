Match each keyboard shortcut with its action in Microsoft Word.

Ctrl + C Copy selected content
Ctrl + V Paste copied content
Ctrl + Z Undo the previous action
Ctrl + S Save the document

Remember that Ctrl + C copies selected content, Ctrl + V pastes copied content, Ctrl + Z reverses the previous action and Ctrl + S saves the document.

Match each table feature with its correct description.

Header row Identifies the contents of each column
Merge Cells Combines two or more cells into one
Split Cells Divides one cell into several cells
AutoFit Adjusts column width to suit the contents

Remember that a header row identifies column contents, Merge Cells combines cells, Split Cells divides a cell and AutoFit adjusts a column to suit its contents.
