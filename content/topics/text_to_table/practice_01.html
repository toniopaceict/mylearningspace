Scenario

You work as a course coordinator supporting the Institute Director. The director wants to understand how students’ assessment marks relate to two factors: classroom attendance and the number of hours spent studying at home each week.

In the Data sheet, you have a dataset for 25 students. For the first 20 students, the assessment mark is known. For the final 5 students, the assessment mark is blank.

Your job is to use multiple linear regression in Excel to build a forecasting formula that predicts assessment marks using classroom attendance and hours of study at home as the independent variables.

Task 1

Go to the sheet containing the student data and use the Data Analysis ToolPak to perform a Regression analysis.

  1. Set the Input Y Range to the Assessment Mark (%) column for the first 20 students.
  2. Set the Input X Range to the Attendance (%) and Home Study (hours/week) columns.
  3. Select the Labels option.
  4. Place the output in an empty area of the worksheet.

From the regression output, check that the following values were obtained:

  • Intercept (β₀) ≈ 19.43.
  • Attendance coefficient (β₁) ≈ 0.54.
  • Home study coefficient (β₂) ≈ 2.40.
Task 2

Input the multiple linear regression equation to predict assessment marks for the five students with missing results.

Predicted Mark = β₀ + (β₁ × Attendance) + (β₂ × Home Study Hours)

If your working is correct, the predicted marks should be as follows:
