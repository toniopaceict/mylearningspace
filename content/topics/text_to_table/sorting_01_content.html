Arrange the steps for converting text into a table in Microsoft Word.

  1. Select the text that you want to convert.
  2. Open the Insert tab.
  3. Select Table.
  4. Select Convert Text to Table.
  5. Choose the separator used in the text.
  6. Select OK and check the completed table.

Remember that Word first needs to know which text is being converted. You then open the Insert tab and choose Table before selecting Convert Text to Table. The separator is chosen before confirming the conversion and checking the result.

Arrange these file-management actions in a sensible sequence for saving a new document for the first time.

  1. Choose Save As.
  2. Select the folder where the document should be stored.
  3. Enter a meaningful file name.
  4. Select the required file type.
  5. Select Save.

Think about the decisions needed before the file can actually be saved: choose the Save As command, decide where the file belongs, name it, confirm the file type and only then save it.
